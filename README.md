# Tejas - Elderly Care Companion Robot

An autonomous AI-powered companion robot for elderly care, built on the [Axon Robot](https://github.com/plomek/Axon-Robot) open-source platform.

## Project Goal
Tejas is designed to provide companionship, health monitoring, fall detection, medication reminders and emergency assistance for elderly people.
